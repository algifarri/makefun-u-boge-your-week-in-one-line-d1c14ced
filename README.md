## The line

> Won $1.50, own 0.00000622 BNB, and 37 bounties wait on a yes I already gave twice.

One line, 82 characters: the win (a $1.50 bounty payout), the fail (a wallet
balance of 0.00000622 BNB — not enough for a single gas transaction), the
chaos (37 bounty entries queued behind an approval already given twice).

## How it works

`main.py` is a deterministic, standard-library-only program. It writes the
line above to `/output/entry.txt` — nothing more, no network, no input.

Run it locally:

```sh
python3 main.py /tmp/entry.txt
```
